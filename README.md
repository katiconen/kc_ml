# kc_ml

An exploratory repo for two intertwined goals:

1. **Skill-building** with LLM APIs — practicing how to call, prompt, and structure interactions with models like Claude.
2. **Comparative behavior research** — using those API skills to run small studies that probe how LLM behavior matches or diverges from humans and other animals, drawing on paradigms from behavioral economics and sequence learning.

The current notebook (`PatternSeq_RNN_v0.ipynb`) explores sequence learning with an RNN, and lays groundwork for comparing pattern-learning dynamics against LLM behavior on similar tasks. Expect this repo to grow into a mix of API experiments, small behavioral tasks (e.g. choice/risk paradigms from behavioral economics), and analysis notebooks comparing model outputs to known human/animal findings.

This is a learning-in-public space, so code quality and organization will be rougher than a polished project — the point is iterating and understanding, not shipping.
